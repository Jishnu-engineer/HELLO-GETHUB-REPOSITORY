# Jishnu | Flipbook Portfolio
A page-flipping portfolio (pure HTML/CSS/JS, no build step) with your photo and 3D infrastructure artwork.

## Publish on GitHub Pages
1. Upload all files in this folder to a new GitHub repository.
2. Settings > Pages > Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. Open `https://<your-username>.github.io/<repo-name>/`.

## Edit
- Page content: the `pages` array in `script.js` (keep an even number of pages on desktop).
- Replace `YOUR_EMAIL@example.com`, the LinkedIn URL and phone in the contact page.
- Swap `assets/profile.jpg` for a new photo; replace the 3D images with real site photos (approved only).
